# Demo video script (target 4:30, hard limit 5:00)

Record the screen at 1080p, narrate live. Public link or Kaggle attachment, viewable without login. Run the demo locally first: `.venv/bin/streamlit run demo/app.py`.

| time | on screen | narration |
|---|---|---|
| 0:00–0:25 | Title slide, then the app header | "Cell Painting is becoming a core human-relevant method for toxicology. But a model can score well simply by counting surviving cells. We built an audit that tells you when morphology really adds something — and when it doesn't." |
| 0:25–1:05 | Method figure (the pipeline: profiles → three models → ΔAUROC → power check → BH-FDR → enrichment). Use the README table or a slide. | "For every one of 404 endpoints we train three models on the same compound-grouped folds: the full morphology profile, the paper's one-number cell-count baseline, and a stronger baseline that uses the whole cell-count dose-response curve — still only cell count. We test the difference with a bootstrap, flag endpoints that don't have enough positives, and control the false-discovery rate across all endpoints." |
| 1:05–1:50 | `results/figures/correction_funnel.png`, then `results/figures/null_control.png`, then the app's metric row | "292 endpoints look like a naive morphology win. Only 181 have enough actives and non-hits to say anything — fifty-five percent are indeterminate and we refuse to report them as clean numbers. 95 pass an uncorrected test. But when we shuffled the labels, our plain bootstrap p-values rejected 10 percent of the time at a nominal 5. Calibrated against that null, 64 apparent wins become 15 certified endpoints — and we show the count as a band, because it depends on how wide that null is." |
| 1:50–2:35 | App → Endpoint explorer → select **MT**, then **LDH** | "For the paper's own readouts: morphology beats cell count for metabolic activity — AUROC 0.92 versus 0.87 — with all three image representations. For LDH there is never a certified advantage against the stronger baseline; the one-number baseline would have called it a win. That's what 'weak baseline hides the shortcut' looks like." |
| 2:35–3:15 | App → Compound explorer → pick a compound (e.g. one with hits in MT/LDH) | "Pick a compound: measured readouts across eight concentrations, and for each endpoint the out-of-fold probability — from a model that never saw this compound — next to the cell-count-only probability and the endpoint's verdict. Probabilities are recalibrated; each endpoint shows its calibration slope, because raw model scores are over-confident." |
| 3:15–3:50 | App → "Where does morphology win?" tab (enrichment table, robustness table), then "Example images" tab | "Where does morphology help? Cell-free biochemical assays: never. Cytotoxicity endpoints look favoured, but they simply have four times more positives; control for size and the pattern disappears, so we do not headline it. The real signal is at compound level: morphology adds most for compounds that change cells without killing them." |
| 3:50–4:20 | Scatter figure of indeterminate endpoints; `null_control.png` | "Does morphology add on top of count? A nested model that sees both certifies 23 endpoints, including all 15 — and every endpoint shows the smallest advantage its data could detect. A second morphology source, HepG2 from four imaging sites, agrees on MT and shows again that verdicts depend on baseline strength. For organ-on-chip, the demo's last tab plans a study: with twenty to sixty compounds only large advantages are certifiable, so chip results should be reported with intervals. Reliability: after calibration the permuted-label error rate on held-out runs is 2.6 percent at a nominal 5. Plate, well, batch and replicate counts alone predict labels at chance. Limitations: only large effects are individually certifiable at this sample size, so the count is a band; this is a 2D hepatocyte plate assay, not an organ-on-chip, a single time point, no donor variability." |
| 4:20–4:50 | README on screen, terminal running `scripts/03_run_audit.py --help` | "Everything is CPU-only, seeded, with MD5-verified downloads and an entry script. The audit is dataset-agnostic: point it at any phenotypic profiling dataset with a cell-count-like baseline — including organ-on-chip assays facing the same risk." |
